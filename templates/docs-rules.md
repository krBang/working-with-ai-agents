# 문서 작업장 규칙 (볼트의 `_docs/CLAUDE.md`로 둔다)

<!-- 워크스페이스 규칙 파일이 길어지지 않게, 문서 폴더에서만 필요한 규칙을 그 폴더의 규칙 파일로 뺀 것 -->

- ★**진행중 폴더의 파일명은 `NNN_<제목>_<YYYYMMDD>.md`** — 앞 3자리 채번이 정렬 축이다.
  - **번호는 작성일 순**. 새 문서는 그 폴더의 **끝번호+1**을 붙인다(`012_`). 재번호는 하지 않는다.
  - 과거 문서 **사이에 끼워야 할 때만** `005-1_`을 쓴다. `005_` < `005-1_` < `006_` 순으로 정렬된다.
  - **주제 접두를 반복하지 않는다** — 폴더명이 이미 주제다. `<주제>_<제목>_…`이 아니라 `007_<제목>_20260101.md`.
  - 날짜 접미는 **문서에 적힌 작성일**을 쓴다(파일 생성 시각과 다를 수 있으나 접미를 정본으로 둔다).
  - 목차 문서(`00_<주제>.md`)는 채번 대상이 아니다.
  - ⚠ 기존 파일을 리네임할 땐 **내부 링크·캔버스 파일 안의 경로·메모리·규칙 파일을 함께** 고친다.
    옛 이름이 새 이름의 부분 문자열인 경우 치환을 두 번 돌리면 `009_009_`처럼 누적되니,
    치환은 **한 번만** 실행하고 끝난 뒤 중복 접두 잔존을 검색으로 확인한다.
- 목차 문서·최상위 인덱스에는 상태어를 쓰지 않는다. 링크·제목·한 줄 설명만.
- 과제가 끝나면 폴더를 `보관/`으로 통째 옮기고 최상위 인덱스의 종결 표에 1줄을 추가한다.
