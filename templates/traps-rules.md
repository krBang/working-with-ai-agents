> `[[이름]]` = 메모리 파일 `<memory-dir>/이름.md`. 상세는 그 파일을 열 것.

- 구독 이력 전체를 볼 때 `is_current = true`로 거르지 말 것 — 해지된 구독의 최초 가입 행이 빠진다 → [[subscription-history-filter]]
- ★상태값 `'P'`는 `invoices`에서는 대기, `refunds`에서는 처리 완료 — 컬럼 이름 없이 `'P'`라고 쓰지 말 것
- `invoices` ↔ `invoice_lines`는 (`invoice_id`, `revision`) 두 키로 조인. `invoice_id`만 걸면 개정본 수만큼 곱해진다 → [[invoice-join-keys]]
- 청구 금액 합계에는 `voided = false` 필수 — 무효 처리된 행이 이중 계상된다
- ★★운영 쿼리 = `EXPLAIN` 붙인 한 벌만 + 대형 테이블 조인은 한쪽을 MATERIALIZED 소집합으로. `usage_events`는 시각 범위 없이 조회 금지 → [[prod-query-rules]]
- 테이블 생성 주체를 `INSERT INTO` 검색으로 판정 금지 — ORM `save()`를 놓친다 → [[analysis-and-delegation-rules]]
- ★해지 루틴을 직접 호출하면 좌석 반환 루틴을 이어서 호출해야 한다 — 안 하면 좌석 수가 어긋난다(YYYY-MM-DD)
- ★★파트너 채널 가입은 `subscriptions`에 행이 없다(별도 테이블) — 내부 조인하면 그 채널만 빠진다. 새 API의 테스트에는 채널별 검체 필수
- 메모리에 적힌 DB 컬럼·코드값 주장은 **사용 전 검색 또는 DB 실측으로 재검증**
