# [클라우드 루틴 · 1회] 조사 숙제 템플릿

> 실행: 지정 일시 1회(끝나면 자동 비활성) · 모델: 중간급 · 도구: 웹 검색, 웹 읽기, 셸, 파일 읽기만 · 파일·PR 금지(최종 답변만)

반복 루틴으로 걸 필요는 없지만 한 번은 제대로 조사해 두고 싶은 주제에 쓴다. 4단 골격(상황 / 조사 대상 / 출력 형식 / 규칙)만 유지하고 내용을 바꿔 끼운다.

---

<주제 한 줄>에 대해 조사하고 우리에게 맞는 적용 후보를 정리해 주세요. 답변은 한국어 존댓말, 화면 2쪽 이내.

## 상황

- 우리 스택: <우리 스택>
- 지금 하고 있는 방식: <현재 방식 2~3줄>
- 알고 싶은 것: <결정하려는 것 — 유지할지 바꿀지, 무엇을 도입할지>

## 조사 대상

1. <항목 1>
2. <항목 2>
3. <항목 3>

## 출력 형식

- <표 또는 항목별 정리 — 열 이름까지 지정>
- 우리 적용 후보 최대 5개(난이도·효과·첫 시도) 또는 「유지/변경」 권장 최대 3개

## 규칙

- 첫 단계에서 `date -u`로 오늘 날짜를 확인하고 「조사 기준일」을 답변 첫 줄에 적는다.
- 공식 문서·1차 출처 우선. 날짜와 출처가 확인된 것만 쓰고 지어내지 않는다.
- 확인하지 못한 것은 「미확인」으로 적는다.
- 파일 생성·수정, PR 작성 금지. 최종 답변만 낸다.

## 실제로 던졌던 숙제 세 가지(주제만)

| 주제 | 상황에 넣은 것 | 출력 |
|---|---|---|
| 모델·가격 변화와 위임 라우팅 점검 | `<우리 역할별 모델 배분>` | 모델 표(단가·컨텍스트·지원 종료) + 역할별 유지·변경 권장 ≤3 |
