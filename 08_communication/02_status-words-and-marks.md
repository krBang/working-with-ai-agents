# 상태 표기와 기호

## 1. 기호

| 기호 | 뜻 | 쓰는 곳 |
|---|---|---|
| ✅ | 완료 — **결과를 확인한 것만** | 메모리 상태 줄, TC 결과 |
| ⬜ | 내가 할 일(아직 안 함) | 메모리 상태 줄 |
| ⏳ | 남의 손에 넘어가 기다리는 중 | `⏳타팀(담당·~예상일)` |
| ⏸ | 사용자가 보류한 것 | 「사용자가 먼저 꺼낼 때까지 언급 금지」와 함께 |
| ⛔ | 하지 말 것(금지·차단) | 함정, 정리 금지 구역 |
| ★ | 실제 사고가 났던 중요 항목 | 함정 파일, 규칙 문서 |
| ⚠ | 주의·경고, 재검증에서 오탐 | 함정, 리뷰 지적 표 |
| 미확인 | 읽지도 실측하지도 못한 것 | 어디서나 — 빈칸 대신 |

기호는 **메모리와 작업 문서 안에서만** 쓴다. 코드 주석에는 쓰지 않는다(리뷰어가 읽는 산출물에서 튄다).

## 2. 남의 손에 넘어간 일은 ✅가 아니다

**규칙** 다른 팀·다른 담당자에게 넘긴 항목은 `⏳타팀(담당·예상일)`로 둔다. 예상일을 모르면 기록일 + 14일을 적는다. **결과를 확인한 뒤에만** ✅로 바꾼다. 세션을 시작할 때 날짜가 지난 `⏳`만 사용자에게 한 줄로 묻는다.

```
⏳타팀(운영 담당 · ~MM-DD)      ← 넘긴 직후
✅운영 반영 확인(MM-DD)          ← 결과를 본 뒤
```

**Why** 「그쪽에서 추가하기로 했다」는 말을 ✅로 적어 두었고, 실제 반영 시점을 놓쳤다. 약속은 완료가 아니다.

적용
- 일일 업무 보고에는 ⏳ 항목을 넣지 않는다(내부 판단용 대기다).
- 상태 띠나 정리 스킬이 날짜 지난 ⏳를 찾을 수 있도록 형식을 고정한다(`⏳타팀(` … `~MM-DD` … `)`).

## 3. 종결로 바꾸기 전에

미결을 ✅로 바꾸기 전에 한 번 더 반증한다. 종결 근거가 「부재」(못 찾았다)이거나 「전언 요약」(그렇다고 들었다)이면 종결하지 않고 실측 항목으로 내린다.

**Why** 틀린 ✅는 메모리에 굳어 다음 세션이 확정 사실로 읽는다.

## 4. 상태어는 두 곳에만

| 쓴다 | 쓰지 않는다 |
|---|---|
| 메모리 인덱스의 활성 작업 한 줄 | 주제 목차 문서 |
| 과제 메모리 파일 최상단 스냅샷 | 최상위 인덱스 문서 |
| | 팀 공유 문서(문서의 생명주기 상태는 종결·마일스톤 때만) |

목차와 인덱스에는 링크·제목·한 줄 설명만 둔다.

**Why** 여러 곳에 적힌 상태는 한 곳만 갱신된다.

## 5. 활성 작업 줄의 형식

```
- [과제](과제-파일.md) — <지금 상태> · ⬜<다음> · ⏳타팀(<담당>·~MM-DD) · 작업물: <작업 폴더>@<브랜치> 미커밋N / 대기: <무엇>
```

- 끝난 단계는 지운다. 줄을 덧붙이지 않고 다시 쓴다.
- 날짜는 최신 상태 표기에만 붙인다(이력을 쌓지 않는다).

## 6. 「먼저 언급하지 말 것」 표시

메모리에는 「알고는 있되 꺼내지 말아야 하는」 항목이 있다. 표시를 붙여 인덱스의 보존 구역에 둔다.

| 표시 | 뜻 |
|---|---|
| 먼저 언급 금지 | 사용자가 꺼낼 때만 참조한다. 할 일 목록에 올리지 않는다 |
| 재제안 금지 | 폐기했거나 하지 않기로 한 것. 다시 제안하지 않는다(근거 문서를 같이 적는다) |
| 완전 종결 | 일회성 업무. 비슷한 일이 새로 생길 때만 참조한다 |
| 할 일 제외 | 다른 사람이 처리 중이거나 담당이 아닌 것 |

**Why** 보류한 과제를 매 세션 「이것도 남아 있습니다」라고 꺼냈다. 폐기한 아이디어를 다음 세션이 새 아이디어처럼 다시 제안했다.

## 7. 근거 수준의 표기

| 표기 | 뜻 |
|---|---|
| `파일:줄` | 코드에서 읽음 |
| 데이터 사실 | 조회 결과에 찍힌 것(환경·창을 같이 적는다) |
| 쿼리 재현 | 화면·배치의 로직을 쿼리로 재현한 결과 |
| 전언 「…」 | 사용자가 전한 말(인용) |
| 추정 | 내 추론 |

검증 결과에는 무엇을 기준으로 확인했는지 붙인다 — `✅(배포본)` · `✅(로컬 수정본)`.

## 8. 미결 줄 끝의 괄호

일일노트 「미결·다음」 줄 끝의 괄호는 **메모리 밖**에 반영했을 때만 적는다(팀 문서 PR 등). 메모리 반영은 기본이라 적지 않는다.
