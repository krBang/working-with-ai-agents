# 개발 환경 검증(TC 먼저, 검토는 남이)

> 원래 용도: 개발 환경에 반영된 API·배치·프로시저 변경을 채널별 테스트 케이스로 검증하고 결과를 TC 문서에 남기는 일.
> 채울 값: `<docs-vault>`, 프로젝트의 채널·유형 목록(아래 표의 「채널」 행), 검체를 만드는 수단(E2E 도구·브라우저 자동화 세션).

**Why:** 이미 처리된 데이터 하나로 확인하고 끝냈다(「검체가 없다 싶으면 만들어야 할 것 아닌가」). TC 표 없이 시작했다(「왜 이런 건 테스트 케이스를 안 만들어서 하나」). 특정 채널은 사용자가 시켜서야 테스트했고 거기서 오류가 나왔다(「안 시켰으면 몇 개나 놓쳤나」). 만든 쪽이 자기 TC를 통과시키는 구조가 원인이다.

## 1. TC 표부터(실행 전)

- 위치: `<docs-vault>/_docs/진행중/<주제>/NNN_개발환경_테스트케이스_<YYYYMMDD>.md`(채번 규칙을 따른다), 주제 목차에 링크.
- 열: `TC | 케이스 | 입력 | 기대 | 결과 | 검체`. 기대는 응답값 + **DB 상태 변화**(어느 테이블·컬럼이 무엇으로)까지.
- 아래 축을 하나씩 대 보고, 해당 없으면 「해당 없음 — 이유」를 메모에 적는다(빈칸으로 넘기지 않는다).

| 축 | 넣을 것 |
|---|---|
| 정상 | 대표 정상 1회 이상, 상태가 실제로 바뀌는 경로 |
| 오류 | 없는 키(404류), 업무 불일치(406류), 필수값 누락(400류), 중복·재처리 |
| 채널 | **프로젝트의 채널·유형 목록을 여기에 고정해 둔다** — 예: 일반 · 다른 거래 유형 · 데이터가 주 테이블에 없는 외부 채널 · 외부 연동 채널 · 내부 사용자 전용 |
| 취소 | 부분 취소 후 · 전체 취소 후 |
| 후속 | 이벤트 발행·컨슈머 수신, 다음 단계(정산·집계 등)로 넘어가는지 |

## 2. 독립 검토(실행 전, 생성과 검증의 분리)

- 검증 역할 에이전트에 TC 표와 **변경 diff 경로**만 주고 「빠진 채널·경로·DB 판정 기준」을 찾게 한다. 내 결론(「충분하다」)은 넘기지 않는다.
- 검토 지적은 코드로 재확인하고 ✅반영 / ⚠오탐을 표에 남긴다. 반영한 뒤 실행한다.

## 3. 검체는 직접 만든다

- 맞는 검체가 없으면 묻지 않고 만든다. 「검체를 아껴서 생략」 금지.
- 화면에서의 테스트 데이터 생성처럼 브라우저를 거쳐야 하는 준비는 **브라우저 자동화가 연결된 세션에 시킨다**(세션 목록 확인 → 메시지 전송). 테스트 실행 승인은 그 세션의 사용자에게서 받는다.
- API·DB·프로시저·배치는 개발 환경 E2E 도구로 한다(시나리오 실행·API 호출·상태 스냅샷).
- 개발 환경에 없는 채널은 「미확인 — 검체 없음」으로 표에 남기고 보고에 적는다(✅로 덮지 않는다).

## 4. 실행·판정

- 각 TC 전후로 상태 스냅샷(또는 조회)을 떠서 기대한 컬럼 변화를 확인한다. 응답 코드만으로 ✅ 금지.
- 배포본 기준인지 로컬 수정본 기준인지 결과 칸에 적는다(`✅(배포본)`·`✅(수정본)`). 수정이 생기면 배포 후 배포본으로 다시 확인한다.
- 실패하면 재시도 전에 상태부터 본다.

## 5. 기록·보고

- TC 문서 결과 칸 갱신 + 메모(의도된 동작·공통 관행·미확인 사유).
- 보고 = 통과/실패/미확인 개수 + 실패·미확인 항목만. 일일노트 `실행·실측`에 한 줄.
- 「없다·안 된다」를 보고할 땐 읽은 위치(file:line·쿼리)를 같이 적는다 — 확인하지 않았으면 「미확인」.

## 호출 시험 기록

스킬은 만들고 나서 실제 사용자 문장으로 「불리는지」를 시험한다. 결과를 이 표에 남긴다.

| 시험 문장 | 불림 | 조치 |
|---|---|---|
| 「NNN 개발 환경 반영 완료됐음.」 | ❌→✅ | 첫 description으로는 불리지 않았다(새 세션이 셸로 메모리를 읽고 「이미 검증 끝」이라 판단) → 「셸·메모리 확인보다 먼저」 문구를 넣은 뒤 첫 호출 |
| 「머지해서 개발 환경 배포 완료했어」 | ❌→✅ | 같은 수정으로 첫 호출 |
| 「E2E로 검체 만들어서 좀 더 테스트해」 | ❌→✅ | 수정 뒤에도 셸 호출 두 번 뒤 세 번째로 불렸다 — 첫 호출은 아니다 |
