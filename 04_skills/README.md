# 스킬

> **공개판 안내** — 이 폴더에는 코드가 들어 있지 않다. 각 장치가 무엇을 막거나 돕는지, 왜 그렇게 설계했는지만 남겼다. 파일 이름은 원본 구성을 설명하려고 그대로 적었다.

직접 만들어 쓰던 스킬을 업무 내용을 걷어 내고 다시 쓴 것. SKILL.md는 절차 문서로 그대로 읽을 수 있다. 딸린 스크립트는 공개판에서 뺐다.

| 스킬 | 언제 불리나 | 원래 용도 | 딸린 파일 |
|---|---|---|---|
| [`daily-standup`](daily-standup/SKILL.md) | 「업무 시작」「업무 정리해줘」 | 매일 아침 팀 공유 문서에 붙여 넣는 전일/금일 업무 보고. 메모리 정리와 주간·월초 정기 점검을 얹어 돌린다 | `branch_tidy.py`(월초 브랜치 정리 후보) · `set_clip_html.ps1`(HTML 클립보드) |
| [`dev-verify`](dev-verify/SKILL.md) | 「개발 환경 반영됐어」「검증해줘」 | 반영된 변경을 채널별 테스트 케이스로 검증하고 TC 문서에 남기는 일 | — |
| [`query-plan-check`](query-plan-check/SKILL.md) | 운영 쿼리를 넘기기 직전, 실행계획을 점검할 때 | 사용자가 운영에서 직접 돌릴 쿼리의 실행계획 함정 사전 점검 | `check.py` · 설정·예시 파일 |
| [`memory-tidy`](memory-tidy/SKILL.md) | 「메모리 정리」, daily-standup 시작 시 | 메모리 인덱스를 로드 한도 안으로 유지 | `measure.py` |

예약 실행되는 두 작업(주간 세션 회고·주간 팀 문서 후보)은 스킬이 아니라 예약 작업 정의라서 [`templates/routines/`](../templates/routines/README.md)에 뒀다.

## 스킬을 만들 때 지킨 것

| 원칙 | 이유(Why) |
|---|---|
| description에 **사용자가 실제로 하는 말**을 넣는다 | 「~할 때 쓴다」는 추상 설명으로는 불리지 않았다 |
| 반드시 먼저 실행돼야 하면 description에 「다른 확인보다 먼저」를 쓰고, 그래도 안 되면 입력 훅으로 실행 지시를 붙인다 | 새 세션이 메모리를 먼저 읽고 「이미 했다」고 판단했다 |
| **호출 시험 기록**을 스킬 파일 끝에 남긴다 | 어떤 문장에서 불리고 안 불리는지가 다음 수정의 근거다 |
| 「손대지 않는 것」을 맨 위에 적는다(정리류 스킬) | 자동 정리가 일하는 방식의 코어를 깎지 않게 |
| 「묻는 것」을 한정해 적는다 | 내부 관리 스킬이 매번 승인을 구하지 않게 |
| 계기가 된 실패를 **Why**로 남긴다 | 절차만 있으면 왜 그 단계가 있는지 잊고 건너뛴다 |
| 스크립트로 뺄 수 있는 단계는 스크립트로 | 측정·추출을 매번 즉석에서 짜면 결과가 흔들린다 |
| 읽기 전용 스크립트와 실행을 가른다 | 후보만 뽑고, 지우는 것은 사람이 고른 뒤에 |
| 스킬·메모리는 고치면 즉시 반영된다(재시작 불필요). 규칙 파일은 재시작이 필요하다 | 수정 직후 목록 갱신으로 확인했다 |

## 옮기지 않은 것

| 대상 | 이유 |
|---|---|
| 정형 자료 요청에 정본 조회문을 값만 바꿔 내주는 스킬 | 내용 전체가 특정 조직의 데이터 구조와 요청 절차다. 패턴(「정본 템플릿은 값만 치환 — 재설계 금지」)만 [실행 규율 3](../01_principles/04_execution-discipline.md)에 남겼다 |
| 조직의 데이터 표준 사전을 조회하는 스킬 | 조직 전용 표준과 서비스에 묶여 있다 |
| 변경 내용을 풍부한 HTML 설명으로 만드는 스킬 | 외부에 공개된 프롬프트에서 온 것으로 보여 저작 여부가 불분명하다. 「이런 스킬을 깔아 썼다」 정도만 적는다 |
| 오케스트레이션 플러그인이 제공하는 스킬·에이전트 정의 | 제3자 저작물. 위임 역할(구현·설계 검토·검증)에 그 플러그인의 에이전트를 활용했다 |
| 도구 플러그인에 딸린 스킬(참조 조회·E2E 실행) | 도구 코드와 함께 다닌다. 설계는 [`06_tools-catalog/`](../06_tools-catalog/README.md)에 설명으로 남겼다 |
